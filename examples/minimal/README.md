# Minimal graph examples

Offline demos of `rlmflow.minimal.nodes` — no Flow, no LLM.

| Script | What it shows |
|---|---|
| [`deep_tree.py`](deep_tree.py) | Build a deep supervise tree with `append`, print ASCII, plot PNG/SVG |

```bash
python examples/minimal/deep_tree.py
python examples/minimal/deep_tree.py --depth 3 --branch 2 --show
```

Writes under `examples/_runs/minimal-deep-tree/`.
